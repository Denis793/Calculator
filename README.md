## 🔹 Features

- Basic operations: **Addition (+), Subtraction (-), Multiplication (\*), Division (/)**
- **Clear (AC)** button to reset input
- **Plus/Minus (+/-)** toggle
- **Percentage (%)** calculation
- **Decimal point** input
- **Responsive layout** for a better user experience
- **Dark mode** with bright accent highlights

---

## 🔍 How It Works

- Button clicks are captured and the display updates immediately.
- Operations are stored and evaluated when the **equals (=)** button is pressed.
- Special functions like **AC**, **+/-**, and **%** are handled through dedicated logic.

---

## 💡 Technologies Used

### ✨ HTML

- Defines the calculator’s structure: display, number buttons, operator buttons, and special function buttons.

### 🌟 CSS

- Applies a **modern dark theme** with vibrant accent colors.
- Utilizes **Flexbox/Grid** for organizing buttons neatly.
- Adds **hover effects** and **subtle shadows** for a 3D feel.

### ✨ JavaScript

- Manages all **button interactions** and **calculations**.
- Dynamically **updates the screen** with each input.
- Handles **input sequencing**, **operation chaining**, and **special functions**.
